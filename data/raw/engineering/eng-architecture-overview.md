# System Architecture Overview — PKC Assistant Platform

## 1. Overview  

The PKC Assistant Platform (PKAP) is PKC Technologies’ flagship AI‑driven productivity suite, delivering conversational assistance, code generation, and analytics across web, mobile, and enterprise back‑ends. The platform is built on a micro‑services architecture hosted on a hybrid cloud (AWS India (Mumbai) + on‑premise data centre in Bengaluru). The first production release (v1.0) is slated for **15 Oct 2026**, aligning with the post‑Diwali rollout window.

## 2. High‑Level Architecture  

| Layer | Primary Tech Stack | Key Services | Deployment |
|-------|-------------------|--------------|------------|
| **Presentation** | React 18, Flutter 3, Angular 15 | PKAP‑Web UI, PKAP‑Mobile (iOS/Android) | CDN (CloudFront) + Edge caching |
| **API Gateway** | Kong 2.8 (K8s Ingress) | Auth, Rate‑limit, Request routing | Multi‑AZ (Mumbai) |
| **Business Logic** | Spring Boot 3, Node.js 20, Python 3.11 | Conversation Engine, CodeGen Service, Analytics Engine | Kubernetes (EKS) – 6 node‑pools (2 x m5.large, 4 x c5.xlarge) |
| **Data & Storage** | PostgreSQL 15 (RDS), MongoDB 6 (Atlas), Redis 7 | User Profiles, Session Store, Model Artifacts | RDS Multi‑AZ, MongoDB Global Cluster |
| **AI/ML** | NVIDIA A100 GPUs (on‑prem), SageMaker (India) | LLM fine‑tuning, Embedding Service, Speech‑to‑Text | 4 GPU nodes (₹2.8 crore CAPEX) |
| **Observability** | Prometheus, Grafana, ELK Stack | Metrics, Traces, Log aggregation | Hosted on‑prem (₹1.2 crore OPEX) |

## 3. Core Components  

- **Conversation Engine** – Powered by a proprietary 7B LLM fine‑tuned on internal codebases; latency target ≤ 150 ms per turn.  
- **CodeGen Service** – Generates boiler‑plate code in Java, Python, and TypeScript; uses a separate 3B model for deterministic output.  
- **Analytics Engine** – Real‑time usage dashboards; stores aggregated events in ClickHouse (₹45 L monthly OPEX).  
- **Security Hub** – Centralised IAM (Keycloak), API token rotation, and data‑masking pipelines compliant with ISO 27001 and Indian IT Act 2000.

## 4. Data Flow  

1. User request → **API Gateway** (TLS 1.3) → **Auth Service** (JWT, 15‑min expiry).  
2. Authenticated call routed to **Conversation Engine**; request cached in **Redis** (TTL 5 min).  
3. Engine queries **PostgreSQL** for context, invokes **GPU‑accelerated inference**.  
4. Response streamed back via **WebSocket** to UI; audit log persisted to **MongoDB**.  
5. All events emitted to **Kafka** → **Analytics Engine** → Grafana dashboards.

## 5. Security & Compliance  

- Data at rest encrypted with AES‑256; keys managed by AWS KMS (₹3.5 L annually).  
- Regular penetration testing scheduled on **Republic Day (26 Jan)** and **Mahashivratri**.  
- GDPR‑equivalent “Data Protection Bill” compliance: user data retained ≤ 180 days unless opted‑in.

## 6. Deployment & CI/CD  

- GitHub Enterprise (₹1.8 L per year) + Argo CD for GitOps.  
- Automated pipelines run on **GitHub Actions** with self‑hosted runners (₹60 L CAPEX for 12 runner nodes).  
- Blue‑Green deployments with traffic shifting via **Kong**; rollback window ≤ 5 min.

## 7. Monitoring & SLA  

- Uptime SLA: **99.9 %** (monthly downtime ≤ 43 min).  
- Alerting via PagerDuty (₹2.4 L per annum) with on‑call rotation covering **Indian Standard Time** and **US Central Time** for the Austin satellite.  
- Monthly performance report generated by **DataDog** (₹1.2 L/month).
